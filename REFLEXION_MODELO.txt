REFLEXIÓN SOBRE EL DESARROLLO DEL SITIO WEB

Este proyecto me permitió integrar HTML, CSS, JavaScript y PHP en un sitio web de varias páginas para una institución educativa ficticia. Durante su construcción comprendí la importancia de organizar el código en carpetas, separar los archivos públicos de los privados y reutilizar componentes como el encabezado, el menú y el pie de página mediante require_once.

También aprendí que un formulario no consiste únicamente en mostrar campos. El servidor debe recibir los datos, limpiarlos, validarlos, conservar los valores cuando hay errores y almacenar únicamente los registros válidos. Para proteger la información, las salidas se escapan antes de mostrarse y los archivos CSV se guardan fuera de la carpeta pública. Además, se utiliza bloqueo de archivo para evitar escrituras simultáneas y se neutralizan valores que podrían interpretarse como fórmulas en una hoja de cálculo.

En la parte visual trabajé con variables CSS, rejillas y reglas responsivas para adaptar el sitio a celulares, tabletas y computadores. JavaScript permite abrir el menú móvil, animar cifras y filtrar las experiencias sin recargar la página. La accesibilidad también es importante: por eso se incluyen etiquetas asociadas a los campos, estados ARIA y navegación con teclado.

Como mejora futura, antes de utilizar un sistema de este tipo con información real sería necesario implementar controles adicionales de acceso, políticas de tratamiento de datos, copias de seguridad y una infraestructura de producción segura. Para las pruebas académicas se deben utilizar exclusivamente datos ficticios.
